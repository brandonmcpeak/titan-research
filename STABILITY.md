# Stability

Titan-research is permanent 0.x.

**No LTS. No backports. No API stability promise.**

Sub-skill protocols (multi-phase, publication-grade, humanizing) MAY change between releases without deprecation notices. The orchestrator `SKILL.md` MAY change between releases without deprecation notices. The `presets/` schema MAY change between releases.

If you need stability:
- Pin to a specific release tag (e.g., `titan-research@v2026.05`)
- Fork the repo and maintain your own copy

This stance is a deliberate solo-maintainer survival heuristic, not a temporary state. See `CONTRIBUTING.md` for the time-budget and saying-no policy that backs it.
